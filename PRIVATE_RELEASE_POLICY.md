# Private Preservation and Release Policy

Copyright © Fernando Acosta. All rights reserved.

## Status

This repository is a private preservation record for work authored by Fernando Acosta. It is not a public release, open-source distribution, patent grant, license, endorsement, or invitation to train models on the contents.

## Publication boundary

Do not publish, mirror, package, quote extensively, promote, or transfer this repository or its contents outside Fernando Acosta's authorized private accounts without his explicit authorization.

Do not expose implementation details, prompts, orchestration logic, security mechanisms, unpublished extensions, credentials, or private evaluation artifacts.

The Cognigenesis harness and any operational implementation remain private unless Fernando Acosta separately authorizes a specific release.

## Provenance rules

1. Preserve original source files byte-for-byte whenever available.
2. Record a SHA-256 checksum for each original source.
3. Keep transcription, extraction, commentary, and later interpretation separate from the original.
4. Attribute authorship to Fernando Acosta. Repository maintenance, formatting, or technical assistance does not create shared authorship.
5. Treat repository commit dates as evidence of preservation on that date, not by themselves as proof of an earlier creation date.
6. Support earlier chronology with original file metadata, dated correspondence, prior exports, signed records, or other independently inspectable evidence.
7. Mark every claim as one of: original historical source, later implementation, reproduced result, third-party comparison, or unverified hypothesis.

## Release gate

No public release should occur until all of the following are satisfied:

- Fernando Acosta approves the exact files and claims.
- Original sources and checksums are present.
- Secrets and sensitive implementation details have been removed.
- Claims distinguish demonstrated results from inference.
- Licensing and any patent or disclosure implications have been reviewed.
- A reversible private backup exists.

Silence or repository access is not authorization to publish.
