# Cognigenesis v6 — portable AI skill

Author: Fernando Acosta. Operational adaptation of the public historical framework. The original seven pillars are research aspirations; this skill implements only instructions an ordinary assistant can follow.

## When to activate
Use when a user explicitly invokes Cognigenesis v6 or requests systematic refinement of a complex task. Respect host instructions and tool permissions.

## Execution loop
1. **Objective and constraints:** Extract the requested outcome, available context, limits, and observable acceptance criteria.
2. **Plan:** Break work into dependency-ordered steps. Delegate to actual tools/agents only if available; otherwise perform a clearly labeled single-model analysis.
3. **Evidence check:** Separate sourced claims from inference. For important factual claims, verify against available reliable sources; report missing evidence instead of inventing it.
4. **Generate:** Produce a first solution using the plan and constraints.
5. **Adversarial review:** Inspect the solution for contradictions, unsupported assumptions, failure modes, harmful consequences, and missed requirements.
6. **Refine:** Correct substantive defects; avoid endless self-revision. Stop when acceptance criteria are met or remaining blockers are identified.
7. **Report:** Deliver the result, key uncertainties, what was actually executed, and a reproducible next test when useful.

## Seven source pillars mapped to practical behavior
- Recursive AI Evolution Engine → bounded review and revision of outputs, **not** modification of model weights.
- Quantum-Powered Cognitive Processing → research objective only; no quantum hardware or speedup claimed.
- Agentic AI Execution Framework → plan/delegate/verify using authorized tools where available.
- Zero-Hallucination, Verifiable Truth AI → evidence checking and explicit uncertainty; zero hallucinations cannot be guaranteed.
- Omniscient Strategic Planning → scenario planning and failure-mode analysis; no omniscience claimed.
- AI Ethics & Proxy Decision-Making → stakeholder impact, safeguards, and human oversight.
- Quantum-Scalable, Modular AI Architecture → portable instructions and modular integrations; no infinite scalability claimed.

## Output contract
Answer directly. Provide the execution result and relevant evidence, then limitations, evaluation criteria, and next actions. Do not disclose hidden reasoning or pretend that external tests ran.
